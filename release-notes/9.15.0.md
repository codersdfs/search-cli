# v9.15.0

A new data source in the terminal: Hacker News, available both as a standalone
command and as a mode in the main TUI.

## Hacker News

`ghfind hn` (or `ghfind hn top`) browses the public Hacker News API with no
authentication:

- Feeds: `top`, `new`, `best`, `ask`, `show`, `job` (with the usual aliases —
  `topstories`, `jobs`, and `askstories`/`showstories`).
- Interactive viewer for a bare `ghfind hn`: feed tabs, `j`/`k` navigation,
  `Enter`/`o` to open a story, `c` to open its discussion, `r` to refresh.
- Pipeable output like the rest of the CLI: `--json`, `--csv`, `--markdown`,
  `--count`, and `--limit`.
- In the main TUI, a Hacker News card on the landing screen opens a fifth mode
  with clickable feed tabs and a results/detail split, using the same keys.

Robustness: every request times out after 10 seconds so a stalled network cannot
hang the CLI or the viewer; dead or deleted stories are skipped instead of
aborting the feed; a failing feed surfaces its HTTP status or network error.

## What did not change

No flags, keys, or output formats outside of `ghfind hn`. The existing four
TUI modes (`landing` / `search` / `trending` / `packages`) keep their
behaviour; `hn` is simply a fifth.
