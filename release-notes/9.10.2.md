# v9.10.2

A one-key release: the export shortcut the app has been advertising in its own
startup tips now exists.

## `Ctrl+E` exported nothing

The tip list in `src/tips.ts` advertises _"Press Ctrl+E to export results as
CSV or Markdown"_. Nothing bound the chord. On the results screen `Ctrl+E` was
ignored outright, and while the query input had focus the line editor's default
emacs binding claimed the same chord as "move to line end" — the one place it
did something, it did the wrong thing.

The key handler now claims `Ctrl+E` before the input ever sees it, and opens
the export overlay: JSON, CSV, Markdown, or plain text.

- With results on screen, `Ctrl+E` goes straight to the chooser — no detour
  through the leader menu (`Esc` → Navigate → Export) — and writes the same
  `ghfind-export-<ts>.<ext>` file the overlay always wrote.
- With an empty result list it does not open an empty chooser: the status bar
  says `No results to export — run a search first`.

## Nothing else changed

The export overlay itself is untouched — the shortcut drives the existing
overlay rather than growing a second code path that could drift from it.
