# v9.10.3

A one-row documentation release: the in-app help screen now lists the export
shortcut.

## The help overlay skipped `Ctrl+E`

`?` (or `Ctrl+H`) opens the keybinding reference. Its **Utility Keys** section
read `t`, `Ctrl+X`, `Ctrl+C` — and stopped there. So `Ctrl+E` was the one key
that ghfind never documented in the place you actually look keys up, even
though everything else already mentioned it: the startup tip rotates through
_"Press Ctrl+E to export results as CSV or Markdown"_, and the README's global
shortcut table carries the row.

It is now the first row of that section, with the other utility keys:

```
Ctrl+E        Export results (CSV / Markdown / JSON / text)
t             Cycle theme (light / dark / solarized)
Ctrl+X        Copy repo URL to clipboard
Ctrl+C        Copy search query to clipboard
```

## Nothing else changed

The shortcut itself landed in 9.10.2; this release only documents it. No
behaviour, output, or CLI surface changes.
