# What's New in ghfind 9.5.0

User profiles from the terminal, plus an org-lookup fix.

### Added

**`ghfind user <name>`** — the user-side counterpart to `ghfind org <name>`

- Fetches a GitHub user's metadata and public repos from the REST API and
  aggregates them into one summary: public repo count, total stars/forks of
  the fetched repos, followers/following, top languages by repo count,
  top 5 repos by stars, and the 5 most recently pushed repos
- `ghfind user torvalds`, `ghfind user @torvalds` (leading `@` stripped)
- Same output flags as `org`: `--json`, `--csv`, `--markdown`, `--count`,
  `--limit`, `--token`
- Organization / Bot accounts are labeled with an `[org]` / `[bot]` badge in
  text output; site admins get `[staff]`

### Fixed

- `ghfind org <name>` joined multi-word names with dashes (`"in tech"` →
  `in-tech`) — now joined with spaces, which the API handles. Single-token
  org lookups are unaffected.

### Internal

- `src/user.ts` mirrors the org-profile module shape: pure normalize/aggregate
  functions, thin formatters, graceful degradation when the repos request
  fails (user metadata is still returned)
- 27 new tests in `tests/user.test.ts`
