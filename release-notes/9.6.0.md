# What's New in ghfind 9.6.0

ghfind now speaks the Model Context Protocol — your coding agent can search
GitHub through it — plus a curl installer and quieter output for `NO_COLOR`
users.

### Added

**MCP server (beta) (`ghfind mcp`)** — ghfind as a tool server for coding agents

- Any MCP client (Claude Code, Cursor, Codex, …) can call GitHub search as
  tools over stdio; zero new dependencies, a small JSON-RPC 2.0 layer over
  the existing modules
- Nine tools: `ghfind_search_repos`, `ghfind_trending`, `ghfind_npm_packages`,
  `ghfind_org_profile`, `ghfind_user_profile`, `ghfind_compare_repos`,
  `ghfind_deep_dive`, `ghfind_bookmarked_releases`, `ghfind_skill`
- Implements the 2025-06-18 lifecycle (initialize → initialized notification →
  operation); also speaks 2025-03-26 and 2024-11-05
- Tool failures report as `isError` results per spec — the agent sees the
  error, not a hang
- Agent searches land in the TUI history like your own searches
- `ghfind mcp --token <t>` pins a token; otherwise config / `GITHUB_TOKEN`
  applies as usual

**`ghfind skill [name]` (beta)** — a token-efficient usage guide for coding agents

- Search syntax, flags, rate limits, and token-efficiency tips, so agents
  stop guessing from `--help`
- Bare `ghfind skill` lists the catalog; the registry (`src/agent-skill.ts`)
  is generic, so third parties can register their own skills alongside the
  built-in `ghfind-cli` one

**Trending language filter** — `ghfind trending` accepts a language slug
(`rust`, `python`, …), validated against the known language list; unknown
slugs are dropped instead of scraping an error page. Also exposed to agents
via the `ghfind_trending` MCP tool. _(The MCP server and agent skill are
beta — surface may still shift in 9.6.x patch releases.)_

**curl installer** — no Node.js needed

```sh
curl -fsSL https://raw.githubusercontent.com/codersdfs/search-cli/main/scripts/install.sh | sh
```

- Detects OS and arch, downloads the standalone `ghfind` binary from GitHub
  Releases, verifies it against the release's `SHA256SUMS.txt`, and installs
  to `~/.local/bin` (or `/usr/local/bin`, overridable with
  `GHFIND_INSTALL_DIR`) — never needs sudo, prints a PATH hint if needed
- Every release now ships a merged `SHA256SUMS.txt` alongside the binaries,
  so package maintainers can verify the same way

**`NO_COLOR` support** — `ghfind --doctor` stops emitting ANSI color codes
when `NO_COLOR` is set (any value, per no-color.org) or when stdout is not a
TTY. Piping `--doctor` into a file or CI log no longer drags escape codes
along.

### Fixed

- **`scripts/brew.rb` was stale and broken** — pointed at the wrong repo
  (`frank/search-cli`), version 0.1.0, and `search-cli-*` asset names that
  never matched the release artifacts. Now targets `codersdfs/search-cli`
  releases with the correct `ghfind-*` names (plus linux-arm64), a livecheck
  block, and a version-pinning test.
- **Community health files** — `SECURITY.md` (private vulnerability
  reporting), `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), and
  `SUPPORT.md` (routes you to `--doctor` first) now exist, so security
  reports and "it doesn't work" issues have proper homes.
