# v9.12.1

A fix release: token handling, honest totals, and one search pipeline.

## The CLI remembers your token

`ghfind login` saved your token to the config file, and the documented setup
flow said it "takes precedence over everything" — except for the most common
command there is. One-shot `ghfind "<query>"` read only `GITHUB_TOKEN`, so the
saved token was silently ignored and every scripted search ran at 60 requests
per hour with no hint why.

Every surface — CLI, MCP server, TUI, watch mode, release checks — now
resolves tokens through one module: flag > surface state > config file, with
the environment variable winning over the file exactly as the docs promise.
The config file's optional `githubTokens` array (a list for round-robin
rotation past the rate limit) is now wired in too; it was declared in the
schema but never connected to anything.

## Errors that say what GitHub said

Nine hand-rolled `Authorization` header builders had drifted into nine
different failure messages. Everything now crosses one seam:

- **401** → bad-token, with the inline fix hint (`t` in the TUI).
- **403 with `x-ratelimit-remaining: 0`** → rate-limit, with the reset time.
- **any other 403** → forbidden, carrying GitHub's own message — SAML SSO,
  secondary limits and org restrictions are indistinguishable from the status
  code alone, so the message now names the cause GitHub itself reported
  instead of asserting the wrong one.
- **anything else** → network error.

## Totals that don't lie

`ghfind pkg <query>` tells you how many matches there are — except npm,
crates.io, NuGet and Maven Central substituted the page length when the
registry published no total and printed it as an exact count. They now report
a bound (`30+`) like RubyGems always did, in `--count`, the packages toolbar,
the browser footer and the MCP payload.

## One search pipeline

The parse → filter → validate → search → rank flow existed as nine hand-wired
copies across the CLI, MCP server, TUI and watch mode, with three different
ideas of what a bad query meant. It lives in one module now, and zero-result
loosenings are computed once and offered everywhere: the TUI's ranked "try
this instead" suggestions also ship in the MCP `ghfind_search_repos` tool
(`suggestions` in the payload, a `Try:` line in the text), and the CLI prints
them to stderr.

The five package-registry providers are descriptors behind one shared
clamp → fetch → guard path; the `30+`-style bound rendering lives in one
formatter instead of three.

## Also

- `ghfind_trending` (MCP) no longer advertises a `token` argument it could
  never use — the trending feed is an unauthenticated HTML scrape.
- README and HOW-TO now document `githubTokens` and the token precedence;
  the test count reflects the real suite.
