# v9.14.0

Two additions: a repo health score across four weighted dimensions, and a
third theme with a real picker in the TUI.

## `ghfind health <owner/repo>`

```
ghfind health facebook/react
ghfind health oven-sh/bun --json
ghfind --compare facebook/react oven-sh/bun nodejs/node --health
```

The score weighs four dimensions: maintenance activity (30% — push recency
blended with commit volume over the trailing 90 days), issue responsiveness
(25% — closing throughput, PRs filtered out), release cadence (25%) and
community breadth (20% — contributor count). Each dimension prints its own
bar and a plain-language reason, so "why 74?" is always answerable.

Three decisions keep the number honest rather than flattering:

- **A missing signal never silently scores 0.** Every endpoint fetch degrades
  independently, and the total re-normalizes over the dimensions that did
  produce data. When nothing at all answered, the total is null and the UI
  says so instead of grading a repo D.
- **Archived repos are capped at 40.** A frozen mirror can be a perfectly
  good repo, but it is not "maintained" — the cap keeps it out of A/B while
  the output explains why.
- **100 means "100+".** A full result page is a cap, not a count; commits,
  issues and contributors all report it that way in both the score and the
  reason text.

A `/releases/latest` 404 is treated as "no releases published" — a real
signal, scored on repo age — not a fetch failure.

## Deep-dive gains the same score

`ghfind deep-dive a/b` and the MCP `ghfind_deep_dive` tool now include the
health breakdown. The contributors request is shared between the section and
the community count (fetched once at `per_page=100`), and the health signals
run alongside the README fetch, so the deep-dive stays one round of requests.

## Dracula, and a theme picker

The TUI now ships three themes: `tokyo-night`, `premium-dark` and
`dracula` — the official Dracula palette. Pick one under **Menu → Theme**
(Enter applies and persists it), cycle with `t`, or set
`ghfind --theme dracula`. The `--theme` help row, the init wizard and the
TUI picker all read from the same registry, so a new theme only has to be
registered once.
